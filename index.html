CalculusLab User Guide & Shortcuts

Navigation & Graph Controls:

  • Pan Graph: Click and drag anywhere on the grid canvas.
  • Zoom In / Out: Use your mouse scroll wheel, pinch on touchpads, or click + / - on the HUD.
  • Drag Control Points: Click and drag the highlighted points on curves (e.g. point x_0, bounds a and b, center a, point c).
  • Supported Functions: sin(x), cos(x), tan(x), exp(x), ln(x), sqrt(x), abs(x), polynomials like x^3 - 3*x.

Deploying to GitHub Pages:

This is a 100% static web application with zero build requirements. Simply push this repository to GitHub, go to Settings → Pages, select branch main and folder / (root), then click Save!
